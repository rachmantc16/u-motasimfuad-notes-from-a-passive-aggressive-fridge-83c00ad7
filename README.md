A small Node program that writes a single passive-aggressive note (≤200 characters, no trailing newline) from a smart fridge to its owner into `/output/entry.txt` — dry, petty, and very specific about the yogurt. The output is deterministic: run it twice and the file is byte-identical.

## Run it

```sh
node main.ts
```
